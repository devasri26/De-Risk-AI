Platform Documentation

Welcome to the De-Risk AI diagnostic console. This guide introduces the platform's core functions and configuration keys.

📊 Overview & Core Engine

De-Risk AI uses large language models configured via senior technical architect templates to audit startup ideas, code architectures, database scaling decisions, and security postures. It assesses structural failures before engineering teams write code.

💡 Diagnostic Preset Prompts

Presets demonstrate the engine's capabilities. Clicking any preset chip populates the input editor with structured parameters testing microservices scaling, crop health imaging telemetry, or industrial predictive algorithms.

📝 Local Database & Export Files

Every calculation is saved locally to your browser's persistent storage engine (`localStorage`). You can browse previous audits, open them instantly, or copy summaries formatted as Github Markdown tags. Use the browser print dialog to export a cleanly compiled PDF report.
